# AstrBot 帮助菜单

自动列出已启用插件和标准指令，用 HTML 模板生成图片发送到聊天。内置 AstrBot Plugin Page 编辑器，可调整菜单外观、插件介绍、指令说明、顺序和可见性。

## 安装

要求 **AstrBot >= 4.26.0**，并配置可用的 AstrBot HTML 文转图服务。

推荐在 AstrBot WebUI 的插件管理中使用仓库链接安装：

https://github.com/huvz04/astrbot_plugin_help_menu

也可以把整个 `astrbot_plugin_help_menu` 文件夹放到 AstrBot 的 `data/plugins/` 中，安装 `requirements.txt` 后重启或重载插件，或在 AstrBot WebUI 上传 ZIP 安装包。

插件安装后，打开 **AstrBot → 插件 → 帮助菜单 → 菜单编辑器**。不需要额外端口、服务或前端构建。页面通过 AstrBot 自带的登录和 Plugin Page bridge 访问后端。

## 聊天指令

| 指令 | 功能 |
| --- | --- |
| `/帮助` | 查看插件功能菜单，默认最多发送 4 页 |

需要时可附加关键词或页码，例如 `/帮助 生日`、`/帮助 2`。

`/` 是示例唤醒前缀，实际跟随当前会话的 AstrBot 配置；也可以在编辑器中指定菜单展示的前缀。展示前缀和用法不会改变真正的指令注册。末尾的独立数字表示页码。

截图失败时发送文字菜单，并在 AstrBot 日志中记录错误。相同内容默认缓存 300 秒，配置或指令变化后自动使用新截图。插件配置页可调整缓存、截图超时和单次最多发送页数。

## 编辑器

- 自动扫描已启用插件、普通指令、指令组、完整子指令路径、别名、参数和说明。
- 修改插件显示名称、分类、介绍，以及指令描述和展示用法；留空恢复自动获取的内容。
- 隐藏插件或指令，设置顺序，数字越小越靠前。
- 添加手动菜单条目，补充正则触发、消息事件等无法自动扫描的用法。手动条目只做展示，不会创建新指令。
- 提供樱花、纸笺、夜色主题，可调整强调色、图片宽度、分栏数、分页条目数、标题和页脚。
- 实时预览草稿，生成当前页实际截图并下载；点击“保存菜单”后聊天立即生效。
- 导入、导出 JSON 配置。多个页面同时编辑时，以配置版本检测冲突，避免覆盖其他页面的修改。

聊天会过滤全局停用、当前配置未启用、当前会话停用的插件，以及已在 AstrBot 指令管理中禁用的指令。平台与消息类型限制按当前事件过滤。普通用户看不到管理指令；管理员也需启用“向管理员显示管理指令”才会看到。系统插件默认隐藏。

编辑器预览使用全部已加载插件，无法模拟特定聊天的配置、平台和插件自定义权限检查。自定义过滤器不会被菜单扫描执行，避免触发插件业务行为。菜单中的可见条目仍受原插件的真实权限与触发条件约束。

图片中插件介绍最多显示 3 行、指令描述最多 4 行，长内容以省略号收尾。完整文案保留在编辑配置中。

## 数据

设置保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_help_menu/menu.json`，使用临时文件和原子替换写入。不会写进插件代码目录，因此升级插件可保留描述。已经卸载或暂时停用的插件，其自定义内容仍保留在配置中，重新加载后继续使用。

HTML 与截图使用同一个模板 `templates/menu.html`。描述作为纯文本转义，不支持插入 HTML、脚本或自定义模板代码。

## 本地预览与验证

本地不必安装 AstrBot，可以预览编辑器和菜单样式：

```powershell
cd astrbot_plugin_help_menu
python -m pip install -r requirements.txt
python tools/demo.py
```

打开 `http://127.0.0.1:8767/demo/`。这是明确标注的示例数据，不能代表当前 AstrBot 实例；“生成图片”在演示中禁用。演示设置写入 `previews/demo-state.json`，与真实设置独立。

运行核心和插件入口测试：

```powershell
python -m unittest discover -s tests -v
```

当前项目不包含 AstrBot 实例或消息平台凭据。真实平台的图片发送需要安装到 AstrBot 后验证。

已验证：19 项核心与入口测试；Chrome 中的编辑、隐藏、手动指令、分页、主题、管理员预览、保存重载和手机宽度布局；通过 AstrBot 官方文转图服务生成示例菜单 PNG。测试中的插件入口使用 API 替身，示例服务截图不代表已经连接你的机器人。

接口依据：[AstrBot 插件 Pages](https://docs.astrbot.app/dev/star/guides/plugin-pages.html)、[AstrBot 文转图服务](https://github.com/AstrBotDevs/astrbot-t2i-service)。
